6.4 Backend Implementation

The backend is implemented in Node.js utilizing the Express 5 web framework. The server exposes 24 structured REST API endpoints mounted under the /api namespace. Key middleware components include:

• cors(): Configured to support Cross-Origin Resource Sharing across local development ports (5173, 5000, 8080).

• express.json(): Parses incoming JSON request payloads with rigorous body size limits.

• Connection Caching Middleware: Maintains active TCP connection pools to MongoDB Atlas across asynchronous request cycles, preventing socket exhaustion.

6.5 Database Implementation

Data persistence is delivered via a hosted MongoDB Atlas replica set cluster. Ten discrete collections are maintained: users, vendors, categories, products, services, orders, bookings, reviews, coupons, and addresses. Unlike relational schemas requiring heavy joins, MongoDB's flexible BSON document structure allows embedding item snapshots inside orders and package details inside service records, ensuring historical immutability if catalog prices change later.

6.6 API Integration and Service Layer

Client-to-server communication is managed through dual-mode service modules (src/lib/api.ts and src/lib/mongodb.ts). When an active network connection to MongoDB Atlas is detected, the frontend performs live HTTP REST operations. If network degradation occurs or offline sandbox mode is toggled, the application seamlessly falls back to local in-memory mock datasets (src/lib/mockData.ts), ensuring complete operational continuity and zero UI blocking during academic presentations.
