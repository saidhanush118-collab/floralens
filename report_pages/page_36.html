8.9 System Strengths

1. Unified Dual-Domain Architecture: First localized platform combining physical perishable floral retail with calendar-bound event decoration booking.

2. Schedule Integrity Guarantee: Server-side double-booking collision prevention completely eliminates vendor calendar collisions on critical event dates.

3. India-Centric Localization: Native INR currency handling, Indian postal address format, and localized delivery configurations tailored for domestic urban environments.

4. Multi-Role Transparency: Seamless role switching provides instant demonstration capabilities across Customer, Vendor, and Administrator workflows without multi-device overhead.

5. High Performance and Fault Tolerance: React 19 Virtual DOM optimizations and connection-pooled Express API ensure snappy interactions and sub-50ms query responses.

8.10 System Limitations

While FloraLens achieves its core objectives, the following technical limitations remain in the current prototype:

1. Simulated Payment Gateway: Payments utilize Razorpay test sandbox simulation rather than live production merchant bank settlements.

2. Absence of Automated Delivery Route Optimization: Delivery dispatch is monitored through manual stage progression rather than live GPS-based courier tracking.

3. Static Venue Layouts: Event decoration packages offer rich photographic portfolios but do not yet support 3D venue layout visualizers or augmented reality (AR) previews.

4. Cold Chain Monitoring: Freshness guarantees are managed through vendor policies rather than IoT-enabled temperature sensors during transit.
