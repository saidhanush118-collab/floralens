4.3 Technology Stack

The software stack is selected to maximize execution performance, developer type safety, and responsive rendering across diverse devices:

Table 2: Technology stack and subsystem mapping

Subsystem / Layer Technology Version Role in FloraLens System
Core Frontend React 19.2.8 Component hierarchy, Virtual DOM reconciliation, responsive UI rendering.
Language Typings TypeScript ~6.0.2 Compile-time static typing, interface contracts, error prevention.
Build Tool & Bundler Vite ^8.3.0 Hot Module Replacement (HMR), tree shaking, lightning fast production builds.
Styling Framework Tailwind CSS ^3.4.19 Utility-first CSS styling, custom botanical palette, responsive layout breakpoints.
Client Routing React Router DOM ^7.18.4 Client-side SPA routing and role-based route protection guards.
API Server Engine Express.js / Node.js ^5.3.0 RESTful API routing, middleware, CORS handling, payload validation.
Database Cluster MongoDB Atlas Cluster 0 Cloud document store with replica set failover and BSON indexing.
Database Driver MongoDB Node Driver ^7.7.0 Connection pooling, connection caching, and atomic CRUD operations.
Payment Gateway Razorpay Simulator Custom API Simulated sandbox checkout supporting UPI, Netbanking, and Cards.
Iconography Lucide React ^1.55.0 Lightweight, scalable vector icons for interface navigation and status badges.

4.4 Project Components and Directory Structure

Table 3: Project directory structure and subsystem mapping

Path / Directory Architectural Purpose and File Contents
src/components/ Reusable atomic UI elements: FlowerProductCard, DecorationServiceCard, Navbar, Footer, PaymentModal, StatusTimeline.
src/context/ Global application state: AuthContext (authentication and demo roles) and StoreContext (cart, catalog, addresses, orders, bookings).
src/pages/ Route views split into public/, customer/, vendor/, admin/, and auth/ portals.
server/index.js Express 5 REST API handling 24 active routing endpoints for users, catalog, bookings, orders, and reviews.
server/db.js MongoDB connection pool manager implementing connection reuse, ping healthchecks, and reconnection logic.
