6.10 Cart Calculation and Coupon Discount Logic

The shopping cart recalculates totals deterministically upon every mutation. All calculations are executed in Indian Rupees (INR) with standard rounding:

Table 4: Mathematical formulas, pricing logic, and unit metrics

Quantity / Metric Mathematical Formula Notes & Constraints
Item Line Total L_i = P_unit × Qty Calculated per SKU variant.
Cart Subtotal Subtotal = ∑ L_i Sum of all items in cart.
Percentage Discount Disc = min(Subtotal × (R / 100), MaxDisc) Applied if Subtotal ≥ MinOrder.
Flat Discount Disc = FlatAmount E.g., FESTIVE20 flat reduction.
Net Order Total Total = max(0, Subtotal − Disc + Fee_del + Fee_plat) Standard platform & delivery fee added.
Booking Total Total_bkg = P_pkg + ∑ P_addons + Fee_plat − Disc Includes selected event add-ons.

6.11 Payment Integration

FloraLens integrates a simulated Razorpay Sandbox modal supporting Indian payment methods: UPI QR code scanning, Virtual Private Address (VPA), Netbanking across major Indian public/private banks, and Credit/Debit cards. Each successful transaction generates a unique alphanumeric reference (e.g., PAY-SIM-173155829104) correlated with the order or booking document.

6.12 Data Handling, Sanitization, and Error Recovery

All user inputs undergo client-side validation via HTML5 form constraints and React state guards, complemented by server-side sanity checks. Empty postal fields, invalid email formats, and negative stem quantities are rejected with explicit, friendly error messages.

6.13 Testing Methodology

Testing was executed systematically using Vitest and React Testing Library. The test suite verifies store actions (cart increment, coupon application, address addition) and UI component rendering under simulated customer interactions.
