3.4 Specific Objectives

To fulfill the primary aim, the project is structured around ten concrete, measurable technical objectives:

1. Architect a Responsive Client Application: Construct an atomic, component-driven user interface using React 19, TypeScript, Vite, and Tailwind CSS optimized for desktop and mobile viewports.

2. Develop a Scalable REST API: Implement an Express 5 backend server handling structured HTTP endpoints with JSON serialization, CORS management, and centralized error handling.

3. Deploy Cloud Database Persistence: Establish an active MongoDB Atlas replica set cluster with ten document collections enforcing schema constraints and optimized indexes.

4. Engineer Dynamic Product Variant Modeling: Implement a multi-tiered catalog schema supporting Standard, Deluxe, and Premium bouquet tiers with dynamic price and stem calculations.

5. Implement Event Decoration Booking Engine: Build a package customization system allowing customers to select base tiers (Silver/Gold/Diamond), configure add-ons, and schedule dates/time slots.

6. Build Double-Booking Conflict Prevention: Construct a server-side collision validation algorithm preventing duplicate confirmed bookings for identical vendor-date-slot tuples.

7. Provide India-Specific Commercial Localization: Incorporate Indian Rupee (INR) financial math, structured Indian postal address validation (pincodes, landmarks), and coupon calculation engines.

8. Integrate Secure Payment Simulation: Connect a simulated Razorpay sandbox gateway supporting UPI QR, Netbanking, and Card transactions with signature verification.

9. Construct Role-Based Management Portals: Deliver tailored, authenticated dashboards for Customers (order tracking), Vendors (fulfillment progression), and Administrators (KYC approvals).

10. Validate System Reliability: Perform automated unit, integration, and load testing verifying 100% test pass rates across core transactions and sub-200ms API response latencies.

3.5 Expected Benefits

• For Customers: Guaranteed transparent pricing, freshness assurances, convenient home delivery, and elimination of decorator scheduling disputes.

• For Vendors: Enhanced digital visibility, automated inventory tracking, reduction of spoilage, and guaranteed calendar protection against accidental double-bookings.
